# 每周邮箱任务总结

该插件读取当前登录用户自己的交大邮箱和 QQ 邮箱，默认生成最近七天的任务清单，并可为该用户创建每周六 22:00 的自动化。

## 用户配置

登录自己的交小AI账号后，在“每周邮箱任务总结”的工具设置中填写：

- `sjtu_email`：交大邮箱地址。
- `sjtu_password`：交大邮箱密码或邮箱专用应用密码。
- `qq_email`：QQ 邮箱地址。
- `qq_auth_code`：QQ 邮箱 IMAP/SMTP 授权码，不是 QQ 登录密码。
- `timezone`：默认 `Asia/Shanghai`。

每位用户的配置互相独立，不会读取或使用其他用户的邮箱凭据。

QQ 授权码可在 QQ 邮箱网页的账号设置中开启 IMAP 服务后生成。交大邮箱使用 IMAP：

- 主机：`mail.sjtu.edu.cn`
- 端口：`993`
- 加密：SSL

QQ 邮箱使用 IMAP：

- 主机：`imap.qq.com`
- 端口：`993`
- 加密：SSL

## 启用周报

配置完成后，可以在聊天中让交小AI调用 `enable_weekly_email_digest`，或者告诉它“启用每周邮箱任务总结”。插件会为当前用户创建：

- 名称：`每周邮箱任务总结（周六 22:00）`
- 频率：每周六 22:00
- 输出：按紧急、可稍后、仅知悉分组的 Markdown 任务清单
- 投递方式：在交小AI中生成一条新的自动化聊天并通知当前用户

其他用户必须在自己的账号中填写自己的邮箱凭据，并自行启用一次。

## 隐私与安全

- 邮箱密码和授权码保存在当前用户的加密 User Valves 中；需要部署时设置 `ENABLE_VALVE_ENCRYPTION=true` 和稳定的 `WEBUI_SECRET_KEY`。
- 邮件只读，不标记已读，不发送、删除或修改邮件。
- 验证码、一次性安全代码和 URL 查询参数在送入模型前会被过滤。
- 每封邮件正文和总正文量都有上限，附件内容不会读取。
- 邮件摘要仍会交给所配置的模型 Provider 处理；用户应了解其 Provider 的数据策略。
